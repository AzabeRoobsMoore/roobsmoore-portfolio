# AZABE Placide (Roobs Moore) — Portfolio

A responsive, colorful-gradient portfolio starter for an IT Technician & Network Administrator based in Kigali, Rwanda.

## Run locally
Open `index.html` in a browser. For development, you can use the VS Code Live Server extension.

## Personalize before publishing
1. Confirm the skills in `index.html` and remove anything you do not personally use.
2. Replace the three sample project cards with real projects, screenshots, and working demo/repository URLs.
3. Replace social links with your exact YouTube, Instagram, and X profile URLs.
4. Add your CV as `assets/cv.pdf` if you want a downloadable CV link.
5. Review contact details and spelling.

## Publish
You can deploy this static site with GitHub Pages, Netlify, or your own hosting provider.
